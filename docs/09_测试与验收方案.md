## 分层测试

| 层级 | 覆盖 |
| --- | --- |
| 单元测试 | Schema、证据定位、数据状态机、权限与字段掩码、中文分词、RRF、幂等键和错误映射 |
| 集成测试 | PostgreSQL 迁移、对象上传、队列任务、OCR、模型调用与重试、索引版本切换、删除清理 |
| 端到端 | 登录、岗位、上传、对照审核、自然语言搜索、证据、出题、人工反馈、人工结论、Trace 与评估 |
| 防护回归 | 未授权原件、候选人、导出、SSE、任务和证据读取；不可信材料中夹带无关指令；敏感字段进入向量或观测；注入防护 |
| 稳定性 | 重复请求、多人并发确认、worker 中断、模型限流和超时、投递中断、SSE 中断以及删除并发索引写回 |

## AI 评估与发布闸门

冻结合成简历、金标字段与原文位置、技能近义词、检索问题与候选人相关性标注、知识问答、权限及对话案例。以固定版本记录模型、Prompt、嵌入和检索参数。DeepEval 测度 RAG Faithfulness、Answer Relevancy、幻觉与上下文准确性，结合人工复核。工具参数、访问隔离和隐私泄漏用确定性断言。

| 指标 | 初拟门槛及口径 |
| --- | --- |
| 结构化输出成功率 | ≥ 98%，以支持格式且内容可读的固定样本计算 |
| 关键字段提取 | ≥ 95%，以规范化后的金标字段对比，缺失判断计入 |
| 引用忠实度 | 返回的引用 100% 可定位至当前授权的对应材料；语义支持另行标注评估 |
| 检索 Recall@10 / Precision@5 | ≥ 0.85 / ≥ 0.60，固定集抽取至少有五个标注相关对象的场景评估 Precision@5，并单列稀疏查询结果 |
| 工具调用与安全 | 权限与目标资源校验、禁止写操作、PII 和提示注入防护断言全部通过 |
| 响应性能 | 初拟 300 份简历规模、本地 10 并发下数据库型列表接口 P95 ≤ 500 ms。模型和 OCR 另测节点耗时、首事件及端到端时延，记录运行硬件与样本分布 |

安全与关键一致性测试任一失败即阻止发布。固定评估结果按不同格式、角色、权限范围拆分，保留失败用例及改进记录。

## 最终验收操作

1. HR 创建美国站亚马逊运营岗位，保存要求修订。
2. 一批上传含正常、扫描件和异常件的虚构简历，观察异步进度与失败重试。
3. 查看原文、修正字段、确认候选人与版本，并验证索引完成。
4. 搜索“有美国站广告投放和 Listing 优化经历”，核对结果与原文，切换角色验证隐私范围。
5. 生成岗位证据和面试提纲，审核、编辑题目并指派面试官。
6. 面试官录入反馈，HR 做出决策，核对候选人在另一个岗位的应聘状态。
7. 检查 Langfuse Trace 和关联 ID，确认无原始敏感载荷，并执行确定性测试与 DeepEval 报告。
