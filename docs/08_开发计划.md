# 开发计划

> 第一阶段已实现基础业务并通过 SQLite 本地测试，正式基础设施验收状态见 [进度记录](11_开发进度与问题记录.md)。已前置实现应聘关系、流程流转、基础上传及人工面试反馈。

v0.1 · 待评审。阶段按依赖推进，设计确认后开始代码实现。

| 阶段 | 主要交付 | 退出标准 |
| --- | --- | --- |
| 1 基础工程 | Vue、API、Compose、迁移、RBAC、工作台、岗位、候选人基础与种子数据 | 空库可迁移、前后端联通、三类业务角色权限验证、岗位与候选人可增查改、数据库统计核对 |
| 2 简历解析 | 单份／批量上传、MinIO、OCR、解析与审核、去重、索引任务 | 五种格式通过实际解析，失败可重试，部分失败不污染批次，人工确认后生成真实索引 |
| 3 人才检索 | 关键词、向量、RRF、Rerank、搜索 Agent、证据页面 | 用自然语言命中特定经历，显示可定位原文，跨角色检索隔离，固定集通过检索阈值 |
| 4 面试与流程 | 招聘知识库、RAG、证据分析、面试题、人工反馈与招聘流转 | 一人多岗互不影响，两轮面试可追溯，问题可编辑，人工决策有完整历史 |
| 5 AI 助手 | ChatAI、短期记忆与摘要、改写、路由、工具、SSE | 查询进度、搜索、知识问答与题目草拟通过实际工具，流式断线可恢复历史，跨会话与越权访问受控 |
| 6 工程化 | Langfuse 完整 Trace、DeepEval、离线评估数据、性能与边界测试、部署说明 | 可从干净环境启动并完成端到端验收，发布闸门、日志脱敏、后台恢复和清理验证通过 |

阶段 1 建立最小可运行数据子集与权限测试。合成数据规模最终为 300 份有效候选简历、15 个岗位、30 份知识文档、200 道校核面试题，另补格式错误与重复测试附件、历史应聘及面试记录。后续逐步完善不同质量简历、英文与中文材料、扫描件、技能近义词和长文档。AI 关键链路从首次引入时记录运行 ID，最后一阶段补齐外部观测与发布门禁。

## 待评审事项

- HR、业务负责人、面试官的具体数据可见范围、导出和原件下载分配。
- 关键招聘状态是否允许重开，以及岗位关闭后的未完成应聘处理。
- 模型供应商、服务区域和数据配置。开发默认使用合成数据。
- Docker Desktop 的引擎访问，或使用可访问的 Linux 容器环境。
