# AI 数字化人才平台 · 项目总览

> 2026-11-26 第一阶段更新：评审通过后已进入实施。当前运行结果、基础设施待验收项及源代码启动文档见 [开发进度与问题记录](11_开发进度与问题记录.md) 和 [README](../README.md)。下文的环境表是 v0.1 评审时的记录。

状态：v0.1 设计评审稿。日期：2026-11-26。所有功能均为拟建，当前交付为设计文档。

平台面向模拟的深圳跨境服装企业，约 200–300 人，经营亚马逊美国站。HR 管理招聘、面试官准备和记录面试、业务负责人管理所负责岗位。开发和验收使用标记为 SYNTHETIC 的虚构数据。

## 首条验收链路

创建亚马逊美国站运营岗位 → 批量上传简历 → 异步解析 → HR 核对原文并确认 → 建立人才索引 → 自然语言检索 → 查看证据 → 生成并编辑面试题 → 面试官填写反馈 → HR 决策 → 查询历史 → 查看 Langfuse Trace → 执行 AI 评估。

## 范围与工程决策

本期覆盖岗位、候选人、简历、检索、证据分析、面试、流程、招聘知识库、ChatAI、权限及系统运维。员工档案、组织架构、培训、绩效、薪酬和第三方业务系统对接均在本期范围之外。部门名称是岗位字段。候选人在不同岗位拥有独立应聘记录，系统保存人工决策。

采用单企业模块化单体，网页、API、异步 worker 共享一个应用版本。PostgreSQL 保存业务真相及向量数据，Redis 承载任务投递和短期缓存，MinIO 保存原始文件。建议沿用 ric-train 中经过评估的接口和实现模式，复用边界详见架构文档。
