# 接口设计分册

已从当前 FastAPI 实现导出 [接口定义.openapi.json](接口定义.openapi.json)，可用于联调；开发环境的交互式文档为 `/docs`。

## 9. API 设计

统一前缀 /api/v1；错误结构含 code、message、request_id，不回传模型网关原始敏感错误。
分页采用 page/page_size（上限 100）；任务与资源使用 UUID。
所有端点在控制器校验权限；不接受前端任意 Cypher、SQL、Milvus 表达式或文件路径。

| 方法与路径 | 目的／关键响应 |
| --- | --- |
| POST /auth/login | 用户名密码；建立 JWT；返回用户与角色摘要 |
| POST /auth/logout | 失效当前 jti、清除 Cookie |
| GET /auth/me | 当前用户、角色与权限 |
| GET, POST /users | 管理员分页查账号／建账号 |
| PATCH /users/{id} | 管理员启停、角色分配；增加 auth_version |
| POST /resumes | multipart 文件；202 + task_id、document_id |
| GET /tasks/{id} | state、stage、错误摘要与进度 |
| POST /tasks/{id}/retry | 仅失败可重试任务；保持幂等性 |
| GET /talents | 分页、标签与允许的结构化筛选 |
| GET, PATCH, DELETE /talents/{id} | 档案、编辑触发重建、软删除 |
| GET /resumes/{id}/download | 权限校验后短期签名 URL |
| GET /talents/{id}/evidence | 当前版本字段的原文依据 |
| GET /talents/{id}/revisions | 分页查看事实版本与修改来源 |
| GET, POST /talents/{id}/notes | 独立 HR 备注；返回明确的“未进入匹配／检索”标记 |
| GET, POST /tags | 列出／创建标签 |
| PUT /talents/{id}/tags | 设置关联标签 |
| GET, POST /jobs | 查岗位／创建 JD 与处理任务 |
| GET, PATCH /jobs/{id} | 查岗位／编辑后重建与缓存失效 |
| POST /jobs/{id}/matches | 岗位找人才；eligible、needs_review 两组，分项／证据及 excluded_count |
| POST /talents/{id}/job-matches | 人才找岗位；相同分组、硬条件判定和评分语义 |
| POST /search | question、filters；回答、人才结果、引用 |
| GET /health/live, /health/ready（根路径，无 /api/v1 前缀） | 进程存活／依赖就绪，不泄露配置 |
| GET /admin/integrations/status | 管理员查看脱敏后的依赖状态 |

创建／修改接口使用请求 DTO，禁止直接把 SQL 模型批量赋值；防止请求修改 is_active、role 等未授权字段。
匹配、检索在依赖不可用时返回明确 503／处理中状态，不用假数据冒充真实结果。
档案修改 DTO 包含 base_revision、field_changes 及 evidence_refs；陈旧 revision 返回 409。备注端点只修改独立备注，不重建事实索引。首版备注创建后保留审计，不提供物理删除接口。
匹配响应示例结构：{eligible: [...], needs_review: [...], excluded_count: 0, versions: {...}}，需复核项包含 unknown_conditions。
接口示例与完整 OpenAPI Schema 在实现阶段由 FastAPI 导出并纳入验收。

## 实施补充

- `POST /api/v1/talents/{id}/reparse`：`{"base_revision":1}`，202 返回新 task_id／revision；旧版本或正在处理返回 409。
- `GET /api/v1/resumes/{id}/chunks`：原文切片及 PDF 页码／DOCX 段落；供人工纠正选择来源。
- `GET /api/v1/stats`、`GET /api/v1/tasks`：总览统计与最近100条任务。
- 简历字段纠正示例：`{"base_revision":1,"field_changes":{"skills":["Python"]},"evidence_refs":{"skills":[{"chunk_id":"实际片段ID","quote":"实际原文中的Python"}]}}`。占位示例不可直接调用。
- Bearer 令牌与浏览器 HttpOnly Cookie 均受服务端权限校验；Cookie 写请求还需 `X-CSRF-Token`。
- 下载返回307短期签名 URL，不返回对象存储凭据。
- 匹配／RAG 期间版本发生变化返回409，依赖不可用返回503，模型格式或引用错误返回502。
