# 数据字典（实现快照）

由 `python -m scripts.导出设计产物` 从 SQLAlchemy 模型导出；MySQL 8、utf8mb4、UTC、UUID。
正式升级使用 Alembic；SQL 文件用于查阅和新库建表参考，不重复应用于已有表。

Python 端默认值由应用写入，未标为数据库 DEFAULT。facts、requirements、快照采用 JSON；简历全文使用 LONGTEXT。
